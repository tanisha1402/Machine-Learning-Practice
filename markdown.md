# Table

`normally it's left aligned`
| Left columns  | Right columns |
| ------------- |-------------|
| left foo      | right foo     |
| left bar      | right bar     |
| left baz      | right baz     |

`it can be right aligned by placing : in right side`

| Left columns  | Right columns |
| -------------: |-------------:|
| left foo      | right foo     |
| left bar      | right bar     |
| left baz      | right baz     |

`it can be left aligned by : in left side`

| Left columns  | Right columns |
| :------------- |:-------------|
| left foo      | right foo     |
| left bar      | right bar     |
| left baz      | right baz     |

`it can be center aligned by : in both sides`
| Left columns  | Right columns |
| :-------------: |:-------------:|
| left foo      | right foo     |
| left bar      | right bar     |
| left baz      | right baz     |
